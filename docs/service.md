# 服务方式与交付范围

**计划以订阅服务提供持续维护的跨渠道比价与优惠发现能力。** 用户关注商品与购买条件，服务侧负责渠道更新、数据核实和功能维护。

**秒级信息获取已在德国官方 Outlet 的有限现场测试中验证；正在为预授权自动下单做好准备。** 服务建设将围绕更快取得有效报价、更早发现机会和减少购买操作展开。

当前仍处于产品建设阶段，尚未开放在线订阅。具体覆盖范围、更新目标、通知渠道与服务价格，以后续演示和双方确认的方案为准。

## 面向用户的体验

| 用户要做的事 | 产品方向 |
| --- | --- |
| 更快取得商品信息 | 已验证来源达到秒级采集；各渠道更新目标按实际接入结果说明。 |
| 找到值得关注的优惠 | 多款商品集中展示，按相对德国官网原价的节省比例排序。 |
| 确认自己能买的规格 | 全局尺码筛选、颜色选择及同规格渠道比较。 |
| 判断价格是否可信 | 展示报价来源、库存状态、适用条件和核实时间。 |
| 不必反复手动搜索 | 为关注商品设置价格或节省比例条件，达标后提醒。 |
| 达标后及时启动购买 | 正在准备预授权自动下单流程，执行器接入与实际购买验证尚未完成。 |

## 订阅价值

持续服务的价值在于渠道适配与维护、可追溯的数据更新、同规格比较和个人关注规则。公开仓库用于了解产品，实际服务能力通过管理台提供。

核心实现、内部采集策略、部署配置和账号凭据不随本展示仓库分发。本仓库不提供自行部署的完整软件或源码下载包。

## 演示与验收关注点

演示应围绕实际接入的商品和渠道，核对以下结果：

- 商品版本、颜色与尺码是否正确对应；
- 最低价及德国官网参考价能否追溯到证据；
- 过期、缺货及未知库存是否正确处理；
- 报价和汇率时间是否清楚，已覆盖和未覆盖渠道是否可区分；
- 关注规则是否按用户条件触发，通知与购买执行是否独立控制。

正式服务范围应明确可用渠道、运行时段、通知方式及实际验证的更新目标。价格比较当前以商品标价为准；未来购买执行还需核对最终结账总额。

## 当前开放状态

- 已有秒级采集实测、跨国渠道研究与本地操作台；德国官方 Outlet 一组实测首轮约 2.06 秒，后续 8 轮列表检查平均约 1.22 秒。
- 新版商品橱窗、统一比价与关注流程正在建设。
- 持续汇率与统一通知网关仍需接入、配置与验证；自动下单已进入产品规则与流程准备阶段。
- 尚无公开在线订阅入口，也未开放自动付款功能。
